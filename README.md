# entrequincenas-media

Automatización de la publicación diaria de contenido de finanzas.

- `main` → `automation/`: plantillas y scripts (render.py carruseles, reel.py reels, sonido.py música, preparar.py lee el brief y genera todo).
- `media` → archivos del día (se reemplaza cada día). Metricool descarga de `https://raw.githubusercontent.com/RodrigoLopez17/entrequincenas-media/media/<fecha>/<archivo>`.

Fuentes Bricolage Grotesque e Instrument Sans (SIL OFL). Íconos Lucide (ISC).
